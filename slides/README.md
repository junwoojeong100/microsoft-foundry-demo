# 발표 슬라이드 · Slides

Microsoft Foundry 데모의 발표 덱(PPTX)입니다. 영상과 같은 흐름의 21장이고, 챕터별 데모 영상 14편이 들어 있으며, 발표자 노트에 핵심 메시지와 영상 대본이 있습니다.
The presentation decks for the Microsoft Foundry demo: 21 slides in the same flow as the video, with 14 demo videos embedded and the key messages and the video script in the speaker notes.

- 웹 링크는 Microsoft 의 PowerPoint 웹 뷰어로 열립니다. 슬라이드의 영상에서 ▶ 를 누르면 재생되고, 오른쪽 아래 **NOTES** 에서 발표 스크립트를 볼 수 있습니다. 뷰어는 자체 글꼴을 써서 줄바꿈이 조금 다를 수 있으니, 정확한 모양은 PPTX 를 내려받아 확인하세요.
  The links open in PowerPoint for the web: press ▶ on a slide's video to play it and use **NOTES** for the script. The viewer uses its own fonts, so line breaks can differ slightly — download the PPTX for the exact layout.
- 이 폴더의 PPTX 는 **공개용 사본**입니다. 새 덱은 `python scripts/publish_deck.py <덱.pptx> --lang ko|en` 으로 복사하세요(개인 메타데이터를 지웁니다). 자세한 방법은 [docs/recording.md](../docs/recording.md#슬라이드-덱을-웹에-올리기) 를 보세요.
