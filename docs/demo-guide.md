# 데모 진행 가이드

영상(`video/microsoft-foundry-demo-ko.mp4`)의 흐름을 그대로 **라이브로 시연**하거나, 영상을 틀고 **설명을 덧붙일 때** 쓰는 가이드입니다.
모델 응답은 실행마다 조금씩 다르므로 아래 "기대하는 결과"는 문장이 아니라 **핵심 사실**만 적었습니다.

## 한 문장 메시지

> 부품을 따로 모아 붙이는 대신, **모델·에이전트·도구·가드레일·평가·추적이 이미 이어진 하나의 플랫폼**에서 시작합니다.
> 직원은 ChatGPT 같은 앱으로 쓰고, 관리자는 Foundry 포털에서 운영합니다.

## 시연 전 점검 (5분)

1. `azd env get-value WEB_URI` · `azd env get-value DEMO_ACCESS_CODE` 로 주소와 접속 코드를 확인하고, 앱을 한 번 열어 **Contoso Guide 질문 하나**로 워밍업합니다.
2. Foundry 포털(<https://ai.azure.com>)에 로그인해 `contoso-ai` 프로젝트를 열어 둡니다. 포털은 한국어 UI 기준으로 설명했습니다.
3. 모델 쿼터가 부족하면 응답이 느려지거나 429 가 납니다. 시연 직전에 **포털 → 관리 → 할당량**에서 사용량을 확인하세요.
4. 질문은 아래 표의 시작 질문(앱 화면에도 버튼으로 있습니다)을 그대로 쓰면 실패 확률이 가장 낮습니다.

## 고객이 자주 묻는 질문

| 질문 | 답변 요지 |
|---|---|
| 우리 데이터가 모델 학습에 쓰이나요? | Foundry 에서 고객의 프롬프트와 데이터는 기본 모델을 학습시키는 데 쓰이지 않습니다. 저장되는 데이터는 암호화됩니다. |
| 키 관리는요? | 이 데모는 Foundry 리소스의 **키 인증을 꺼 두었고**(`disableLocalAuth`), 앱은 관리 ID + 역할(RBAC)로만 호출합니다. 포털의 API 키 칸에도 "사용할 수 없음"으로 표시됩니다. |
| 인터넷에 노출되나요? | 데모는 시연을 위해 공개 엔드포인트입니다. 운영에서는 프라이빗 엔드포인트·가상 네트워크로 닫습니다. |
| 한국 안에서만 처리되나요? | 데모는 한국 중부 리전에 리소스를 두지만 모델 배포 유형은 `GlobalStandard` 입니다(처리 위치가 한 곳에 고정되지 않음). 처리 위치 요건이 있으면 배포 유형(`DataZoneStandard` 등)과 모델별 가용성을 먼저 확인하세요. |
| 사용자·팀별로 비용 한도를 걸 수 있나요? | Foundry 는 **배포(모델) 단위 쿼터(TPM)** 까지 기본으로 제공합니다. 사용자·팀별 한도와 비용 귀속이 필요하면 Azure API Management(AI Gateway)를 앞단에 두는 구성을 검토하세요. |
| 모델을 바꾸려면? | 앱 코드는 배포 이름(`gpt-6.1-sol` 등)만 알고 있습니다. 포털에서 새 모델을 배포하고 이름을 바꾸면 됩니다. Model Router 를 쓰면 난이도에 맞는 모델을 플랫폼이 고릅니다. |
| 품질은 어떻게 증명하나요? | 같은 질문 세트로 버전을 채점합니다(`scripts/run_evals.py` → 포털 '평가'). 배포 전에 같은 평가를 돌려 품질이 떨어지는 버전을 막을 수 있습니다. |

## 시연 중 문제가 생기면

| 증상 | 조치 |
|---|---|
| 첫 응답이 매우 느림 | 앱/모델이 잠시 쉬었던 것입니다. 시연 전에 워밍업 질문을 한 번 하세요 |
| `429` / 응답이 끊김 | 포털 → 관리 → **할당량**에서 해당 배포의 TPM 사용량을 확인하고 한도를 올립니다 |
| 앱이 "준비 중"에 머묾 | 첫 기동 때 문서 인덱싱과 에이전트 생성을 합니다. `curl $(azd env get-value WEB_URI)/healthz` 가 `"bootstrap":"ready"` 가 될 때까지 기다리세요 |
| 포털에서 에이전트가 안 보임 | 로그인한 계정에 Foundry 리소스의 **Azure AI User** 역할이 필요합니다(배포한 사람에게는 Bicep 이 부여) |
