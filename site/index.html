직접 해 보기

내 구독에 배포하기

Docker 없이 명령어 하나로, 약 8~10분이면 끝납니다.

터미널
git clone {{repo_url}}.git
cd {{repo}}

az login
azd auth login
azd up                          # 환경 이름 예: contoso-demo

azd env get-value WEB_URI           # 직원용 앱 주소
azd env get-value DEMO_ACCESS_CODE  # 접속 코드

azd down --purge --force        # 다 쓰고 나면 정리
  • {{icon:list-checks}}준비물 Azure 구독(소유자, 또는 기여자 + 사용자 액세스 관리자), Azure CLI, Azure Developer CLI(azd). Docker는 필요 없습니다.
  • {{icon:gauge}}모델 쿼터 선택한 리전에 GPT-6.1 등의 쿼터가 있어야 합니다. 부족하면 infra/main.bicep에서 용량을 줄이거나 멀티벤더 모델을 끄세요.
